# GTA-Clips
## Orb Chase

A small maze-chase arcade game in a single HTML file — open `maze-chase/index.html` in any browser.

- **Move:** arrow keys / WASD (or swipe on mobile) · **Pause:** P
- Collect every spark to clear the maze. Grab a pulsing core to make the sentries vulnerable for a few seconds and catch them for bonus points.
